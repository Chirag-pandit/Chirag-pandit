# 📊 Smart Attendance Dashboard

![Dashboard GIF](https://media.giphy.com/media/v1.Y2lkPTc5MGI3NjExa2s0c3kxanM2ZmpkYmQxdTQ5eTlyOHBqcGZla2xvbHI2ZDNjYzk0MyZlcD12MV9naWZzX3NlYXJjaCZjdD1n/VbnUQpnihPSIgIXuZv/giphy.gif)

> A modern, intuitive **Student Attendance Dashboard** for educators and administrators to manage and visualize attendance records with real-time analytics, charts, and logs.

---

## 🚀 Features

- 📅 **Date-wise & Subject-wise Attendance Tracking**
- 📈 **Interactive Visualizations** (Line Graphs, Bar Charts, Pie Charts)
- 🧑‍🏫 **Individual Student Reports**
- 🟢 Live Status: Present / Absent / Late
- 📊 Data Insights and Overall Analytics

## 💡 Tech Stack

- 🧱 **Frontend**: React.js, Tailwind CSS  
- 📊 **Charts**: Chart.js / ApexCharts  
- 🗃️ **Backend**: Node.js, Express  
- 🛢️ **Database**: MongoDB  
- ⚙️ **State Management**: Redux / Context API
